# Non adaptive background subtraction
Non adaptive background subtraction


This is a tweak in existing motion detector to implement non adaptive background subtraction. The original detector author is Andrew Kirillov, we need to select Detector 4 to view it.
The videos are inside Frames folder in the project folder. This is inside bin\Debug folder, ensure ffdshow_rev4533_20140929_clsid is installed prior to testing it.
